# BiaMeet (بیا میت)

بیا میت یک سیستم ساده و کارآمد برای زمان‌بندی جلسات و رای‌گیری است.

## مرور کلی

بیا میت به کاربران اجازه می‌دهد جلساتی با چندین بازه زمانی ایجاد کنند و دیگران را برای رای‌گیری در مورد زمان‌های مورد نظر خود دعوت کنند. کل برنامه یک کانتینر حدوداً ۲۰ مگابایتی است که در حالت بیکار حدود ۲۰ مگابایت حافظه مصرف می‌کند.

## ویژگی‌ها

- **انواع جلسات منعطف**:
  - **زمان‌های مشخص**: پیشنهاد زمان‌های دقیق برای رای‌گیری.
  - **الگوی هفتگی**: تعیین روزهای مجاز و بازه زمانی برای جلسات تکرار شونده، با لینکی که پس از چند هفته منقضی می‌شود.
  - **بازه زمانی**: تعیین یک تاریخ و بازه زمانی کلی برای پیشنهاد زمان توسط کاربران.
- **اشتراک‌گذاری هوشمند**: پشتیبانی از Web Share API و کپی لینک، همراه با پیش‌نمایش لینک (تصویر Open Graph و عنوان هر جلسه).
- **داشبورد مدیریت**: مشاهده آمار سیستم در `/admin` با توکن `ADMIN_TOKEN`.
- **تجربه کاربری**:
  - تقویم شمسی، فونت وزیرمتن روی خود سرور، حالت تاریک خودکار.
  - طراحی واکنش‌گرا برای موبایل و برجسته شدن زمانی که بیشترین رای را دارد.
  - شفافیت در رای‌گیری (نمایش نام رای‌دهندگان).
  - **رای امن**: با رمز عبور اختیاری فقط خود رای‌دهنده می‌تواند رایش را ویرایش کند. مرورگر به‌جای رمز فقط یک توکن امضاشده نگه می‌دارد.
  - **زمان‌های امن**: شرکت‌کنندگان با نام و رمز خود زمان پیشنهاد می‌دهند و تا وقتی کس دیگری به آن رای نداده، می‌توانند حذفش کنند.

## معماری

- **بک‌اند**: Go + Fiber؛ یک فایل اجرایی که فرانت‌اند را هم (فشرده‌شده با brotli/gzip) سرو می‌کند.
- **دیتابیس**: SQLite در حالت WAL
- **فرانت‌اند**: ماژول‌های Vanilla JS با esbuild + Tailwind CSS
- **دیپلوی**: Docker Compose با یک کانتینر `FROM scratch`

تنظیمات (متغیرهای محیطی) در [README.md](README.md#configuration) آمده است.

## توسعه محلی

### پیش‌نیازها

- Go 1.24+
- Node.js 20+
- Docker & Docker Compose

### اجرا

1. **کلون کردن مخزن**:

   ```bash
   git clone https://github.com/malekpouri/biameet.ir.git
   cd biameet.ir
   ```

2. **اجرا با داکر**:

   ```bash
   docker compose up --build
   ```

   برنامه در آدرس `http://localhost:8085` در دسترس خواهد بود.

3. **اجرای دستی** (دو ترمینال):

   ```bash
   cd frontend && npm install && npm run dev
   cd backend && WEB_DIR=web/dist go run ./cmd
   ```

4. **تست‌ها**:

   ```bash
   cd backend && go test ./tests/...
   ```

## ارتقا از نسخه ۱

نسخه ۲ به‌جای دو کانتینر (nginx و بک‌اند) یک کانتینر دارد که همان volume قبلی را (اکنون در مسیر `/data`) استفاده می‌کند. فقط کافی است دوباره build کنید:

```bash
docker compose down
docker compose up -d --build
```

برنامه هنگام شروع، مالکیت `/data` را (که نسخه ۱ با کاربر root ساخته بود) درست می‌کند، سپس با کاربر غیر root ادامه می‌دهد. اطلاعات قبلی حفظ می‌شود و برنامه همچنان روی پورت 8085 در دسترس است.

## موتورهای جستجو

- فایل‌های `/sitemap.xml` و `/robots.txt` از روی `BASE_URL` ساخته می‌شوند؛ پس `BASE_URL` باید همان آدرس نهایی باشد که پروکسی از آن ریدایرکت نمی‌کند (فعلاً `https://www.biameet.ir`).
- فقط صفحه اصلی قابل ایندکس است. صفحه جلسات، مدیریت و ۴۰۴ با `noindex` ارسال می‌شوند و در sitemap نیستند.
- اگر nginx سرور خودش `/robots.txt` یا `/sitemap.xml` را پاسخ می‌دهد، آن را حذف کنید تا نسخه برنامه سرو شود.
- هر وقت متن صفحه اصلی یا پرسش‌های متداول تغییر کرد، `homeUpdated` را در `backend/api/pages.go` به‌روز کنید.
- در Google Search Console یک property از نوع URL prefix برای `BASE_URL` بسازید، روش **HTML tag** را انتخاب کنید، مقدار `content` را در `GOOGLE_SITE_VERIFICATION` (مثلاً در فایل `.env`) بگذارید، دوباره دیپلوی کنید، تأیید کنید و سپس `sitemap.xml` را ثبت کنید.

## نسخه

نسخه برنامه در `backend/version/version.go` تعریف شده و در پانویس سایت، لاگ شروع، پاسخ `GET /health` و دستور `docker compose exec app /biameet version` نمایش داده می‌شود.
